# Third-party assets

All files below come from the `@pmndrs/assets` package (v1.7.0), released under **CC0 1.0** (public domain).

- `environment/sky.exr`, `environment/sunset.exr`, `environment/night.exr`: HDR environment maps (originally from Poly Haven, CC0), 512×256 EXR.
- `textures/normals/*.webp`: tileable surface normal maps, 512×512 WebP.
  plaster ← 0021, concrete ← 0006, stone ← 0024, pavers ← 0025, wood ← 0019,
  grass ← 0015, leaves ← 0003, bark ← 0001, water ← 0027, fabric ← 0018.
